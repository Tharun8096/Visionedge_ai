# VisionEdge AI - Smart Object Detection

## Overview

VisionEdge AI is a real-time object detection system built using Python, OpenCV, and YOLOv8.

It can detect multiple objects using a webcam and display live information.

---

## Features

- Real-time object detection
- Person detection
- Mobile phone detection
- Car detection
- Bus detection
- Truck detection
- Motorcycle detection
- FPS counter
- Date and Time
- Object Counter
- Live Status
- Detection Log
- Recording Indicator

---

## Technologies Used

- Python
- OpenCV
- YOLOv8
- Ultralytics
- VS Code
